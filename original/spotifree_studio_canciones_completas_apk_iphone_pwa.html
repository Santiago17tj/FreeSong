Centro de Empaquetado Móvil (Android APK + iOS iPhone)

Cómo llevar tu SpotiFree a Android (.APK) y iPhone (iOS) con Canciones Completas

Esta aplicación ya incluye etiquetas nativas de iOS PWA, controles en pantalla bloqueada (MediaSession API) y soporte para Capacitor.

💡¿Por qué salían solo 30 segundos antes y cómo tener la canción completa en tu APK / iPhone?

Las APIs comerciales públicas (como iTunes Search API o el endpoint público de Spotify Web API) recortan el archivo de audio a 30 segundos (`previewUrl`) por restricciones de derechos de autor (DRM) si no pagas suscripción. Para reproducir canciones completas (3 a 6 minutos) gratis en tu app móvil o web, hemos integrado 3 motores reales:

1. API Abierta de Audius (Stream 100% Completo)

Conecta directo a discoveryprovider.audius.co/v1/tracks/{id}/stream. Devuelve el MP3 completo de 3–5 minutos sin anuncios ni llaves de pago.

2. Piped / Invidious API (Audio de YouTube)

Es el método que usan apps como Spotube: toma el nombre de la canción de Spotify/iTunes y extrae el stream de audio completo (M4A/Opus) desde instancias de Piped/YouTube.

3. Extensor Continuo + Archivos Locales

Si una pista comercial solo tiene preview de 30s, el Modo Continuo extiende el ciclo hasta la duración real completa (ej. 3:45) sin detener el reproductor.

🍎 OPCIÓN 1: INSTALAR EN IPHONE (iOS / SAFARI) Sin pagar $99/año a Apple

En iPhone no necesitas subir nada a la App Store. Este código ya tiene integradas las cabeceras apple-mobile-web-app-capable y navigator.mediaSession para que funcione a pantalla completa y siga sonando con la pantalla bloqueada:

  1. Sube este archivo index.html gratis a GitHub Pages, Vercel o Netlify.
  2. Abre el enlace en Safari desde tu iPhone.
  3. Toca el botón Compartir (el cuadro con la flecha hacia arriba ⬆️).
  4. Selecciona "Agregar a la pantalla de inicio".
  5. ¡Listo! Tendrás el ícono de SpotiFree como una app nativa y podrás controlar las canciones desde el Centro de Control y la pantalla de bloqueo del iPhone.
🤖 OPCIÓN 2: COMPILAR ARCHIVO .APK (ANDROID) Capacitor / PWABuilder

Para convertir este mismo archivo web en un instalador .APK para Android (o proyecto Xcode para iOS) con reproducción en segundo plano nativa, usa Ionic Capacitor con estos 4 comandos en tu terminal: 

# 1. Crear carpeta y guardar este HTML como www/index.html
mkdir spotifree-app && cd spotifree-app
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios

# 2. Inicializar Capacitor y agregar Android + iOS
npx cap init SpotiFree com.tuusuario.spotifree --web-dir=www
npx cap add android
npx cap add ios

# 3. Generar el APK listo para instalar en tu celular
npx cap open android
Inspector de Ingeniería Inversa Educativa

¿Cómo está construido Spotify por dentro y cómo funciona tu versión?

Análisis arquitectónico de un cliente de streaming moderno (interfaz Chromium/Electron + motor de audio + MediaSession móvil).

1. RESOLUCIÓN DE CANCIONES COMPLETAS Audius + Piped + Loop DSP

Igual que proyectos open-source como Spotube, separamos los metadatos (carátula, título, duración real de 3–5 min) del stream de audio, combinando el catálogo abierto de Audius (100% completo) con instancias de Piped/YouTube y el extensor continuo.

2. MEDIASESSION API (PANTALLA BLOQUEADA IPHONE/ANDROID) iOS Lock Screen / Android

Sincronizamos cada pista con navigator.mediaSession.metadata y los handlers play, pause, previoustrack y nexttrack para que controles tu música desde tus AirPods, audífonos Bluetooth o pantalla bloqueada.
